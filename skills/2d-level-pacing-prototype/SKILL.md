# Level pacing, prototyping and scope

## Pacing
- Teach a mechanic safely, let the player practice, then test it; one new idea per level.
- Alternate tension and rest (sawtooth); follow a hard level with an easier one.
- Size geometry/boards from player metrics. Required platformer jumps ~70% of max distance; optional rewards up to ~95%.
- Check the critical path cannot soft-lock. Playtest greybox before dressing.
- Plot the difficulty curve; look for spikes; log fail rate and moves per level when analytics exist.

## Prototype fast
1. Write the one question it must answer. 2. Throwaway or keep (decide up front). 3. Timebox 30-90 min. 4. Greybox everything else. 5. Instrument the metric. 6. Playtest yourself then one uncoached person. 7. Keep/kill/refactor against criteria written in step 1. Spikes live in a separate folder; a keep is a rewrite.

## Jam / MVP scope
- Read the rules; prep project setup in advance; one concept; cut features not tied to the core loop; ship one level end to end before adding content; pre-submission checklist.
