# Genre: roguelike

- Core loop: explore -> fight -> loot -> descend; permadeath with optional meta-progression.
- Systems: energy-based turn scheduler, procedural dungeon (see 2d-procedural), symmetric field of view, seeded loot tables, save-on-exit (see 2d-save-systems).
- Everything driven by one seed so runs are reproducible; show the seed.
- Design knobs: run length, hazard ramp, loot rarity, meta-unlocks. Pitfalls: unwinnable seeds, RNG that feels unfair (add pity timers), save-scumming.
